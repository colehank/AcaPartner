# 从工作桌完成一件小工作

先建立本地账号并打开项目。第一次进入可点“开始引导”；也可先关闭，从“使用引导”重新打开。没有数据时先认识模块，不必为完成教学而调用模型或生成结果。

## 一条基础路线

1. **项目与面板**：顶部切换项目；左侧目录管理笔记，中央成果和右侧辅助区可以停靠。切换前留意保存状态。
2. **连续稿件**：点“成果”，在连续正文中阅读或编辑。直接改文字后点“保存文字”；自动同步草稿不等于保存稿件。
3. **批注与整轮意见**：在真实正文选几个字，再新建批注。到“搭档 / 整轮意见”整理意见，试着删除再恢复自己刚写的一条。提交 Agent 是独立动作；不必在基础路线中执行。
4. **科研图**：从“项目工具 → 图 / 来源链”进入。选对象或图位再操作；布局草稿可以撤销，保存、重绘与采用到稿件须分别确认。没有来源的静态图不能推断为可编辑数值。
5. **原生笔记**：点“笔记”，记下一条观察并点“保存”。在“目录 / 搜索”输入原文短语，点击命中返回笔记。项目目录里的 Markdown 是原生文件。
6. **当前 PDF**：打开“论文 PDF”，核对稿件修订；只有需要时才点“编译保存版”。缺少编译器会报告受阻，旧 PDF 不等于新稿已编译。
7. **重开**：分别保存稿件和笔记，再退出登录、重新登录或重开页面。确认内容与对应修订一致。

引导中的“打开此模块”只是导航。上一/下一和目录选择不修改内容；结束或稍后均可重开，已填写内容不会为了教学被重置。

## 进阶模块

- **实际来源**：从图的组成与来源展开数据、脚本和结果链，区分当前版本与固定历史引用。查看来源不授权执行脚本。
- **数据 / 变化重做**：检查输入身份、代码、配方和计划，确认受影响部分后再执行。运行需配置的生成环境；不能只改显示数字代替重算。
- **研究委托**：写清目的和材料，解析已保存来源，再选择已配置路线与预算。没有执行器时提交不可用。
- **有限科研协作**：按目标组织有界任务、分工、审阅和整合。候选不是最终采用结果，科学判断仍需要核实。
- **项目任务**：查看状态、实际用量、问题与候选。暂停/取消可能经历 drain，unknown 必须核对，不能盲目重试。
- **问题与证据 / 稿件 Claim**：查看支持关系、冲突与来源；关系图不能替代科学证据本身。

## 哪些动作可能消耗资源

| 动作 | 影响 |
| --- | --- |
| 阅读、引导、普通编辑和本地保存 | 不调用模型 |
| 编译保存稿 | 本机 XeLaTeX / BibTeX |
| 预览或重绘图 | 运行已授权绘图脚本 |
| 执行生成计划 | 数据计算和可能的外部执行器 |
| 提交研究/整轮/协作任务 | 按配置调用模型，可能产生费用 |

默认本地启动只开放工作桌，不启动模型和队列。实际能否执行以当前权限和运行时提示为准。

## 常见情况

- **出现冲突**：保留当前输入并读取最新版本，不强行覆盖。
- **只看到旧 PDF**：查看其保存稿修订；明确编译新保存版。
- **固定历史图只读**：它用于保持稿内历史；明确打开当前版本后才能改图。
- **不能提交任务**：检查是否配置执行器、路线与权限。反复点击不会补齐环境。
- **关闭了引导**：从“使用引导”再次打开；教学不会自动恢复旧科研任务。
