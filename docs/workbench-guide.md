# 当前科研工作台

首页 `/` 是统一科研工作台。安装和账号位置见[快速开始](quickstart.md)。本文描述当前界面；只保留统一科研工作台。

从首页新进入时，先打开浏览器记住且当前可见的项目研究进展；没有可用记录时打开最近更新的可见项目。切换项目也先回研究进展图；浏览器刷新仍恢复原来的工作标签与草稿。论文直达入口继续按原有规则打开源稿或恢复活动标签。

## 围绕项目工作

左侧选择项目，在研究结构和文件目录之间切换。研究结构以研究、交付、笔记组织内容；文件目录是同一项目内容的另一种视角。中央打开选中内容，右侧提供项目上下文与工作交接。

研究图以项目为唯一根入口；项目名在页头提供上下文，画布不重复绘制项目根 Q，后端根对象仍保留。Q 可并列；父 Q 有子 Q，只组织子问题，不直接拥有 A 或回答 C；叶 Q 没有子 Q，承载一条或多条分析路线。综合判断放在最后一个明确的叶子 Q；A/E/C 各有独立标题、正文、进度和版本，不要求每 Q 填满四个槽位。每 A 最多产生一项可版本化 E，多项 E 可共同进入 C，C 明确回答叶 Q。父问题需核对全部直接子 Q 并独立确认，不自动继承子问题的结论或完成状态；问题拆解与前置条件分别记录。背景、数据、原始记录仍从原有入口读取。词义见[领域词表](product/glossary.md)。

从“新建”添加内容；笔记使用项目的 Markdown 文件。单击文件打开预览标签，双击或编辑后保留标签；留意当前内容的保存状态。长文档在中央内容区内部滚动。

## 查看研究进展

项目页顶部从顶层叶 Q，或父 Q 的最后一个直接子 Q，显示已确认的保存版结论，并标明该叶 Q 的实际编号（本例为 Q1.3），同时显示问题数与已回答数；没有可用结论时显示项目说明或缺口。搭档回复在右侧讨论和记录中读取。打开页面只读取已有研究和任务，不调用模型、执行脚本或改写内容。

研究图标明“最新版本”，画布节点以卡片显示编号、状态、标题和正文摘录，证据可显示结果表节选；具体问题显示 Q1、Q1.1 等，A/E/C 随所属 Q 编号。本例综合叶 Q1.3 有两条分析，显示 A1.3-1、A1.3-2，对应 E1.3-1、E1.3-2，汇入 C1.3；Q1.1 的单一路线为 A1.1/E1.1/C1.1。编号用于阅读，稳定对象 ID 用于引用；编号变化不修改正文、修订或状态。缩远时隐藏摘录并保留短标题；完整内容、来源和历史在下部详情阅读。卡片主体负责选中，独立箭头负责展开，两者均可用键盘操作。已完成 Q 初次收起，未完成 Q 初次展开；手动选择与镜头按项目记住，刷新或状态更新不会覆盖已有展开选择。点击父Q卡片的独立箭头展开或收起子Q，点击叶Q箭头展开或收起已有AEC；点击卡片主体只选中并阅读详情；点击 A/E/C 选择正文及直接关联，始终留在同一画布。从左树或搜索打开问题，会显露所需祖先并定位该问题。

桌面和手机共用从左向右的连续画布；初始镜头优先保留可读的顶层 Q，展开内容可能在屏外，可拖动画布平移，滚轮以指针位置为中心缩放，双指捏合或缩放按钮也可缩放。按住 Space 可平移，双击没有额外动作。“聚焦所选节点”查看所选工作，“查看全局”适应当前可见内容；缩放比例显示在底部。“返回上一视角”恢复此前明确定位、聚焦、全局查看或重置前的镜头及展开快照，最多保留20次，不逐次记录平移；“恢复默认展开”重新按完成状态折叠。节点展开时保留点击位置作为镜头锚点，其他节点可随排版调整；详情固定覆盖画布下部，打开或关闭不缩小画布或自动重置镜头。视角和折叠仅改变本地浏览状态，不修改保存节点、关系、科学状态或草稿。

画布的淡色分区框表示问题归属，顶层 Q 同列、分支按编号排列，展开的综合工作放在可见前置工作之后。灰色无箭头的正交线表示父子层级；有方向的依赖线已兑现为实线、待推进为虚线，Q1.1、Q1.2 通过共享汇合段进入 Q1.3，仍是两条各自有身份的前置关系。端点展开时，类型、方向与兑现状态兼容的关系可共用出线主干或入线汇合段，无法安全合线时保持独立路径。端点折叠时，跨边界关系显示在可见的收起 Q 上；同向同端点的多条关系可汇成一条显示路线，仅全部真实关系已兑现时才显示为已兑现。共享 A/E/C 只要仍有展开的问题路径就继续可见。折叠汇总不新增归属、依赖或科研关系。点单独连线直接查看详情；点共享或汇总路线，或在线上按 Enter/Space，先从菜单选择真实关系，再查看实际类型、端点、兑现状态、版本与依据。Escape 关闭菜单后焦点回到原连线，触屏菜单行至少44px；关系名称不叠在线尾。显式关系仍可从详情撤回并保留历史；“显示回答关系”显示 C 回答 Q 的回指。重复的父→综合子 Q 归属线默认隐藏；在父 Q 的“完成依据”旁点击关联图标，仍可查看对应拆解关系及依据。连线样式不代表系统已验证科学支持。排版暂不可用时可点“重新排版”，晚到结果不能覆盖新的展开状态。

点节点先显示标题、状态与最新正文；详情中的“编辑与状态”可修改标题、正文和进度，“引出新节点”可新增相应类型，“关联已有节点”可建立具名关系并说明含义。父 Q 的“引出新节点”只提供 Q；叶 Q 提供 A 或 Q。已有 AEC 的叶 Q 新建子 Q 时，表单提示“历史保留，完成确认需重新核对”，保存执行“拆分并迁移”：原 A/E/C 身份、正文与历史不变，原分析/回答关系撤回并保留历史，再接到新子 Q。旧项目若显示“现有 AEC 需要移入子问题”，用该入口整理；不能确认混合父 Q 完成，也不能从侧栏或旧创建入口绕过整理。新节点先保存，再核对完成。旧项目若有待提取的 AEC，可明确选择“导入研究图”；迁移保留原 Q 身份、全部 QAEC 正文和历史、论文、笔记及材料，父 Q 的已有 AEC 会接入末尾子 Q，空槽不生成假结果；仅已认证且满足新条件的旧完成记录可转移。原总体 Q 从底部“项目内容”抽屉的“原有研究记录与历史”进入，迁移节点也可明确打开其原有 QAEC；普通问题导航定位研究图，不强制另画根 QAEC。

节点记录待开展、进行中、待确认、已完成或暂缓，旧记录可保持未标记。E 完成需要唯一产生它的 A 已完成，C 需要关联证据完成，叶 Q 需要回答结论及明确的前置 Q 完成；父 Q 需要全部直接子 Q 与明确的前置 Q 完成，且无直接 A 或回答 C。两类 Q 均须填写自己的核对依据、核对准确依赖版本并确认足以作答；父 Q 的勾选文字为“子问题的结论足以共同回答父问题”。子 Q 全部完成也不会自动完成父 Q。阴性结果也可作答，证据不足时保持未完成或暂缓。叶 Q 开展 A 不要求 Q 先回答；父→子的拆解连线保留原方向，完成核对反向绑定每个子 Q 的签名，因此子 Q 变化会沿父问题继续传播待复核；完成依赖和问题拆解分别拒绝循环，科学论证的回指可以保留。

确认绑定准确保存正文、标题、来源、问题范围、关系和依赖签名。它们变化后，当前确认及下游显示“待复核”；恢复旧文字仍需重新确认。旧正文、人工进度与此前确认保留，系统不自动改写结论，也不按填满节点计算完成率。

“版本历史”在详情内只读查看准确保存版，可加载更早版本并“返回最新版本”；主图始终保持当前保存节点。切换节点、关闭详情或切项目后，晚到的历史读取不会显示在新的选择下。当前独立节点历史提供正文阅读；原 QAEC 记录保留其既有历史与比较入口。

新建与编辑的输入按项目、浏览器窗口和节点自动保留为本地草稿。切换节点、关闭详情、取消或刷新后，从工具栏“草稿”继续，也可下载正文或明确删除草稿。保存核对项目与节点的基础修订；冲突时先读取新版、核对后保留草稿重新保存。本地存储失败会提示下载正文。背景、材料与记录、论文源稿和项目内容继续在图下方直接进入。

## 管理目录内容

选中可写目录后点“+”在目录内新建，选中文件后在父目录新建，选中研究问题后建立子问题。笔记限于 `notes/`，Python 脚本限于 `scripts/` 直属目录；未选中节点时，菜单说明每种内容的目标位置。登记内容投影保持只读，默认论文不能删除。

右键节点或按 Shift + F10，可复制路径、名称或研究问题 ID。笔记可在原目录重命名；有未保存草稿时先保存并处理冲突。重命名前会检查指向该笔记及受影响的相对链接，正文链接不会自动改写；检查范围外的链接语法仍需手动核对。

删除笔记或脚本会移到回收站；未保存修改先按基础版本保存，冲突时停止删除。对笔记子目录执行删除时，只逐篇回收其下 `.md` 笔记，不删除目录本身或其他文件。研究问题采用归档，保留子问题与历史修订。可立即撤销，也可刷新后从树节点或目录空白处右键菜单的“回收站”恢复；原位置已有文件时不覆盖。

## 代码、笔记与修改比较

文件目录的 `scripts/` 显示当前项目实际的 Python 工作副本，可编辑、保存、下载和比较修改。保存使用既有脚本服务的 SHA 校验；外部或另一窗口修改后，先比较项目新版，再保留草稿并载入，必要时恢复保留的草稿。保存不会执行脚本或刷新研究结果。脚本限 UTF-8、单文件保存上限 1 MiB。

`code/` 等目录中的登记源码是研究对象引用的固定快照，继续只读。工作副本变化不会替换快照或旧证据。其他代码、配置和资产目前可显示，尚无通用编辑保存入口。

CM6 统一处理源码、笔记和 LaTeX 的选区、搜索、撤销、折叠与按文件名加载语言；主题跟随工作台。笔记的“比较修改”读取真实项目保存版，与当前草稿进行行内比较，保存仍校验原基础版本。

阅读页的 Python、R、LaTeX、JSON、YAML、TOML、Shell、JavaScript、TypeScript、Julia、SQL 代码块采用 Shiki 的 GitHub 明暗配色。未知语言、单块 UTF-8 内容超过 64 KiB 或高亮资源不可用时保留纯文本显示。文件类型图标采用本地 Seti 资源，操作按钮继续使用 Lucide。这里的笔记仍是 Markdown，不提供 Jupyter kernel。

## 编辑论文

从“交付”或文件目录打开论文。新项目先明确选择 DOCX 或 LaTeX；二者分别保存，只有“设为论文源稿”改变项目论文的主源，不自动转换或同步文字。

DOCX 使用 SuperDoc。工具栏右侧选择编辑、修订或阅读；上游提供批注和接受 / 拒绝修订。文件菜单保存到项目或下载当前草稿。没有审阅内容时不预留空批注列；有内容时按可用宽度显示侧栏或浮层。

文件 → 打开建立独立本地标签，保存副本是下载；它不会替换项目论文或回写操作系统原文件。LaTeX 在源码编辑后保存并主动编译，PDF 对应保存源版本，编译失败时应检查环境与日志。

浏览器草稿与项目保存不同。其他窗口或 Agent 提交新版后，先保留草稿再载入；版本冲突不会自动覆盖。刷新、切换和恢复的详细边界见[文稿接入](architecture/document-adapters.md)。

## 与项目搭档协作

研究进展图提供当前保存内容与实际工作入口；搭档回复在右侧讨论和记录中读取。新发送的图变更通过校验后直接保存并刷新画布，无需再进入提案采用页；这只表示研究结构已保存，不表示科学判断已确认。

右侧只有一个“讨论与工作”输入。可以从模糊想法开始，也可以直接要求搭档核对已有记录、分析差异或推进某个问题。发送后就在右侧读取回复，无需先选择探索或委托模式；需要按[快速开始](quickstart.md#明确启用-agent-任务运行器)启用任务运行器，并配置已授权 Codex CLI 路线。

输入上方展开“背景 + 保存内容”，核对或调整本次读取的 Q、登记文字材料、Markdown 笔记和 Python 脚本。每轮同时读取最新研究图的编号、标题、身份、版本、状态与关系摘要；选中图节点后，编号与标题贴近输入显示，该节点的准确保存正文也进入本轮上下文。默认材料优先当前 Q/文件、项目标注的重点材料及少量已有内容；未选中节点的正文不会随整图自动展开，也不会因为目录里存在文件就读取整个项目。界面每次最多选四个 Q、四份原生文件，合计八项保存来源；当前图最多80个节点（含根）、160条关系记录，完整上下文最多45000字节，超限明确拒绝，不截断。原生文件按路径和 SHA 固定为输入快照，不改写源文件。未保存草稿、DOCX 正文、图片和数据表不自动读取。

可以直接要求搭档建立问题、补充计划分析、调整选中节点或连接前置条件。新 Q/A 保持“待开展”；新 E/C 需要本轮用户原话或选定保存材料中的逐字依据，并登记准确来源，保持“待确认”。每轮原话另存为不可编辑的来源；此前回复和提案不能冒充实验依据。修改已有正文前必须读取该节点保存版；无关节点的身份、正文和修订保留。搭档不执行脚本、实验、文件或论文编辑，也不确认科学完成。

每次发送限一次模型分派，默认最长180秒，可在折叠的执行设置中调整路线和时限。它完成已选文字内容的阅读与分析，不执行脚本、实验或改写稿件。最近四轮用于接续讨论；旧回复与提案不是实验证据。“开始新的讨论”不带前序回复。记录页可打开全部工作历史。

普通讨论可以只回复，不改图。有效图变更整批保存后，回复内显示“研究图已更新”和节点数量，画布与左树自动刷新；点击“查看画布”回项目图。图已有并发修改或批次不满足规则时，显示“本轮未修改研究图”，保留回复与未应用结果，可“按当前图重新整理”，不会覆盖较新内容。旧 QAEC 尚未导入时先在画布明确“导入研究图”；搭档不会静默转换原记录。

“撤销本轮”只撤销整批已应用图变更，由研究者操作；新节点归档、新关系撤回、原内容恢复为新修订，回复与历史保留。图已有后续修改时拒绝撤销，按提示在当前图调整；恢复文字不恢复旧科学确认。撤销期间动作禁用，成功后回执显示“本轮图变更已撤销”。它不替代编辑器草稿的撤销。提交响应丢失时，原消息冻结并保留请求身份，用“核对同一消息”接续，不另发一轮。

历史中的旧问题提案仍可改写标题后“加入研究”，旧 AEC 候选仍可比较、编辑后局部采用。省略 `graph_mode` 的旧搭档 API 和 `research.work.*` 保留每 Q 一组 QAEC 的采用合同，不自动映射到独立多 A 图。旧候选采用前仍须处理未保存 Q 草稿并核对保存版；响应丢失时核对同一采用请求。接口及兼容范围见[独立研究图 API](research-workflow/research-graph-api.md#搭档图变更)。

本机文稿文件交接仍可在右侧“稿件工作副本”准备隔离副本，由普通文件工具编辑后按基础版本提交。具体接口与版本保护见[文稿接入](architecture/document-adapters.md#应用接口)。

[科学煮蛋](../examples/scientific-egg/README.md)包含合成数据、真实运行的脚本、图和稿件。按示例说明导入后，可沿问题、数据、分析、证据和论文阅读；模拟数据与平台 Agent 执行状态分别说明。
