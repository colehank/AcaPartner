# 固定工作栏中的自适应标签 v0.16

2026-10-27。用户要求参考Chrome的宽度分配，并消除第一个标签与面板边之间的空白。

Chromium官方[Tab Strip Design (Mac)](https://www.chromium.org/developers/design-documents/tab-strip-mac/)说明先扣除其他控件占用，再给普通标签均分可用宽度，并限制上下界；空间减少时标题、图标与关闭按钮按优先级让位，活动标签保留更大的最小宽度。[Tabs](https://www.chromium.org/user-experience/tabs/)说明标签增多时继续收缩。前一份文档描述历史Mac实现，因此本次采用其布局机制，不宣称复制当前Chrome全部平台细节，也不加入未要求的拖出窗口等能力。

本原型保持栏宽受三栏布局控制；普通标签最大240px，通常等宽。空间不足时缩至非活动28px、活动64px；宽度110/80/64px各阶段让位内部内容。极端超量才在原栏内滚动，活动标签自动显露，不能撑开中间栏。所有完整名称保留在可访问标签和提示中。

首标签左侧padding/gap为0，左侧恢复按钮移到栏末；首标签自身左上角由父面板裁切，选中时与内容面连续。单击预览、双击固定及用户草稿仍保持。
