# 搭档输入到研究图：当前接入

状态：已实现的有限图变更路径，2026-11-05。本文说明当前所有权、发布事务和恢复；字段与精确限额以[图 API](../research-workflow/research-graph-api.md#搭档图变更)为准，用户操作见[工作台指南](../workbench-guide.md#与项目搭档协作)。这不是[目标架构提案](system-architecture-proposal.md)的完成声明。

## 所有权与复用

| 现有模块 | 此路径的职责 |
| --- | --- |
| `frontend/src/workbench/ProjectPartner.tsx` | 共用输入、保存来源选择、预览/提交、原请求核对、回复与历史；新 GUI 消息显式发送 `graph_mode:"edit"` |
| `FreeResearchGraph.tsx`、`context.ts`、`main.tsx` | 将当前独立图节点的真实身份与显示名传给输入；仍由原图读取和本地 Graphviz/React Flow 呈现 |
| `PartnerGraphChange.tsx` | 回复内的应用/冲突/撤销回执、查看画布、继续与整轮撤销；刷新现有研究和项目查询 |
| `project_partner.py` | 同一 `research_partner` 任务的两种显式候选合同、连续讨论、历史与权限入口；旧合同保持原采用行为 |
| `research_graph_changes.py` | 冻结当前图及输入来源、校验变更、在发布事务内应用、以应用后图签名保护整轮撤销 |
| `research_tasks.py`、`commission.py`、Runtime/Providers | 输入 pin、来源/授权复核、有限预算、实际执行、模型回执及事务发布；不增加运行器、队列或对话数据库 |
| `research_graph.py`、Store | 独立 Q/A/E/C、父/叶规则、准确修订、来源、完成有效性、`graph_growth` 关系与历史；继续为人和 Agent 共用权威 |

功能标识为 `partner_graph_changes_v1`，与已有 `project_partner_v1`、自由图和叶问题运行时要求共同检查。原 `.qaec` 记录与独立 A/E/C 不隐式互相覆盖。

## 提交与发布

1. 预览只读取背景、最新图摘要与明确选择的保存正文，返回准确输入 pin；整图只为焦点或明确选中节点展开正文。打开页面、图或历史不调用模型。
2. 提交复核同一 pin、权限、路线与有限预算，将本轮原话保存为不可编辑 `CTX-…` 来源；沿用已有来源快照、任务、grant 和稳定请求账本。同请求重放先核对原任务，不重复派发。
3. 共享 Runtime 执行一次有范围的 Codex CLI 分派。图模式只返回 `partner_reply` 与可空 `graph_change`；没有脚本执行、文件编辑、删除或科学完成字段。
4. `research_tasks.publish` 核对执行身份、授权、来源和匹配的实际模型回执，保存固定回复候选，再在同一 Store 写事务内调用图应用。
5. 图应用比较冻结整图 pin；通过后在 savepoint 内建立节点、关系与可选背景更新，复用现有图规则核对。任何图内失败回滚整批图修改，回复与候选仍可发布并带未应用回执。成功登记稳定节点/关系 ID、应用后 pin 和恢复所需的原内容。
6. GUI 历史查询发现任务或图回执变化时刷新既有研究和项目查询，画布原位更新。图保存没有第二次提案采用；模型任务的审阅字段也不等于科学确认。

新 Q/A 为待开展；新 E/C 必须以本轮用户原话或选定保存材料的逐字引文和准确来源登记，保持待确认。先前回复和提案不是实验证据。既有正文只能在该保存版已进入上下文时替换，无关节点保留身份、修订和内容；内容或范围变化按已有签名机制使确认待复核。现有引用与科学确认历史不因自动应用被删去。

## 并发、撤销与旧合同

冻结图之后的并发变化使整批结果保持未应用，不采用最后写入者覆盖；用户可在当前图继续一轮。关系不合法或旧 QAEC 尚未导入时同样保留回复与未应用说明。已有 AEC 叶 Q 的拆分和已有 Q 的重新组织仍走明确的整理接口，模型图合同只增加关系，不自动删除或重新归属。

撤销由研究者调用 `research.partner.graph.undo`。服务在同一事务内核对项目权限、任务归属和当前整图仍为本轮应用后版本；有后续变化即拒绝。成功时归档新节点、撤回新关系、恢复被改内容为新修订，更新原任务回执并保留所有历史。重复撤销返回已撤销状态。恢复旧文字不会恢复旧确认的有效性，后续科学完成必须重新核对。

省略 `graph_mode` 的旧搭档任务及 `research.work.*` 继续返回每 Q 一组 QAEC 的问题/AEC候选，经原采用组件处理，不自动映射到独立多 A 图。旧 QAEC 先明确导入才允许图模式自动应用；旧记录、原总体问题与历史入口保留。
