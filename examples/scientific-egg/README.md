# 科学煮蛋：完整科研项目示例

**全部样本是合成数据。** 数值由公开的未校准生成模型产生，分析、图和文稿由脚本实际计算与组装；没有开展真实煮蛋实验，也不冒充所引论文的复现。此示例不提供食品安全或食用建议。

目标是同一枚鸡蛋的**蛋白凝固、蛋黄柔软且成形**。本案例用0–10的指数判断：蛋白凝固指数≥7.5，蛋黄软度指数在5–8.5内。蛋黄指数越高越软，超过8.5也可能过稀；两项必须来自同一个 `sample_id`，不能用不同鸡蛋或两组平均值拼成成功结果。

后端保留“科学煮蛋”项目根；画布由页头项目名提供上下文，不绘制额外根 Q。原总体问题及其完整 QAEC/历史可从“项目内容”查阅。桌面和手机使用同一连续画布，已完成问题初次收起，未完成问题初次展开：

- **Q1 哪种煮蛋方法能够使蛋白凝固、蛋黄柔软。** 父 Q1 组织三个叶 Q：Q1.1核对蛋白凝固，Q1.2核对蛋黄柔软且成形，末尾 Q1.3比较四种煮法的逐枚联合达标。A1.3-1/E1.3-1提供联合计数，A1.3-2/E1.3-2检查缺失读数的最有利上界。前者支持C1.3，后者限定解释范围，不再重复单项表。E1.1/E1.2只直接支持各自结论，在综合分析中作为准确保存来源引用；不直接连C1.3。Q1.1/Q1.2仍是Q1.3的前置问题。当前Q1及三个子Q已核对完成，范围仅为本例描述性比较。
- **Q2 冷热交替煮蛋法对鸡蛋大小与下锅温度的泛化性。** 初温指4°C冷藏或22°C室温，不是水温。父 Q2 组织 Q2.1大小/初温、Q2.2批次过程、Q2.3判据敏感性，以及末尾综合叶 Q2.4。A2.4-1综合三项已有报告与缺口，保持进行中；E2.4-1为证据覆盖核对、C2.4为阶段判断，均待确认，不重复Q2.1的分层表。A2.4-2“固定程序后做独立批次验证”待开展，没有虚构 E；Q1仍是选定待检程序的前置问题。

当前核对图有34个节点（含项目主题根）、47条有效关系。父 Q 不直接拥有 A 或回答 C；节点身份、旧正文修订、原 QAEC 和撤回关系历史均保留。每项 A 最多一项可版本化 E，多项 E 可汇入 C，原问题、论文与笔记保留。详见[自由研究图](../../docs/research-workflow/free-research-graph.md)。

- 原始数据：480枚模拟蛋、4种程序、4个批次、3档质量和2档初温；40,080条温度记录；4行缺失保留。
- 真实计算：双节点热响应、逐样本配对判据、分母核对、分批与分层统计、阈值敏感性；不编造显著性。
- 图：4张双面板图，PNG/PDF/SVG及源数据；均有合成标记。
- 交付：带图、表和原生公式的中文 DOCX、独立 LaTeX 主稿和 Markdown 来源。
- 来源：固定种子、变量字典、代码/输入/输出SHA-256与真实本机执行回执。

## 重建

Python 3.12+，安装本目录 requirements.txt；本机还需 Pandoc。DOCX由Pandoc转换，模板样式使用python-docx。中文LaTeX PDF由工作台现有编译器生成，需要将服务配置 rendering.latex 设为 XeLaTeX，并安装 ctex/Fandol 字体包。编译器未配置时导入会明确报告预览不可用。

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run_demo.py
.venv/bin/python scripts/verify_demo.py
```

也可按序独立运行 scripts/01_simulate.py、02_analyze.py、03_plot.py、04_write_paper.py。原始CSV在相同种子与依赖版本下逐字节复现；PDF/DOCX的生成时间或字体环境可能改变二进制文件，不要求其SHA恒定。

绘图复用matplotlib，矢量文字可编辑。提供实际测得的面板坐标与本次图形审计结果。外部作者侧图形审计器不是重建数据与图形的必要依赖；没有安装时不应声称重新完成了该审计。

## 导入工作台

启动仓库的本地工作台后：

```sh
python scripts/05_publish_demo.py --base-url http://127.0.0.1:8924
```

导入使用现有项目、数据快照、登记脚本、不可变资产、科研Q、原生笔记和文稿接口；不直写数据库。每次导入建立新项目，保留其他项目及其草稿。执行回执明确标为本机脚本运行，不会伪造平台后台任务或模型调用。

DOCX与LaTeX是本次批量组装的两份独立保存稿；编辑其中一份不会自动同步另一份。此例演示现有平台能力与来源组织，不声称实时聊天、SSH执行、任意多文稿或完整科研Harness已经实现。

已有本案例时，可只更新背景、问题和阅读文案，保留项目身份、数据资产、用户笔记及现有论文：

```sh
python scripts/05_publish_demo.py --base-url http://127.0.0.1:8924 --update-project PRJ-实际项目ID --receipt /私人目录/case-update.json
```

更新使用准确修订检查，先保存旧版快照；回执路径必须是新的。背景集中说明数据来源，问题正文解释目标、判断方法和实际结果，不在每个页面重复放置来源声明。

新导入已通过 `05_publish_demo.py` 接入独立图。已有本案例需要从原 QAEC 记录适配时，可运行：

```sh
python scripts/free_graph.py --base-url http://127.0.0.1:8924 --project PRJ-实际项目ID --receipt /私人目录/free-research-graph.json
```

新导入通过 `free_graph.py` 接入父/叶结构。已有独立图只需整理原父 AEC 时，也可运行：

```sh
python scripts/leaf_graph.py --base-url http://127.0.0.1:8924 --project PRJ-实际项目ID --receipt /私人目录/leaf-research-graph.json
```

脚本只接受 `demo=scientific_egg_v1`，通过与人和授权 Agent 相同的 `workbench.graph.*` API 核对准确修订，不直写数据库。`free_graph.py` 先提取非空 AEC，再建立案例汇总与待开展验证；`leaf_graph.py` 用原子整理接口将父 Q 的原分析/回答关系撤回并保留历史，原 A/E/C 接到末尾 Q1.3/Q2.4。重复适配不重复建立综合 Q；遇到已由用户修改的综合内容会停止覆盖。原 Q 与 A/E/C 身份、正文、旧修订、原总体问题、论文、资产、笔记及其他项目均保留，空槽不制造结果。

`free_graph.py` 的新导入和重复适配都会调用 `revise_graph.py` 整理当前案例关系与综合正文。已有独立图可只做这次修订：

```sh
python scripts/revise_graph.py --base-url http://127.0.0.1:8924 --project PRJ-实际项目ID --receipt /私人目录/revised-egg-graph.json
```

修订前保存快照，通过准确项目/节点修订逐项写入；正文已被用户改过时在首次写入前停止，冲突不覆盖新工作。脚本从原始CSV重算联合计数和缺失上界，保留原QAEC、论文与笔记。只针对此前已完成的案例判断按新内容与依赖重新核对；Q2综合范围扩大后回到进行中/待确认，新导入不会因文字已有而自动完成。重复执行不追加修订。

结构调整不自动批准科学完成。脚本仅针对先前已认证的计算与判断，按新范围和依赖签名记录新的核对说明；Q1.3及父 Q1的确认分别保存，待开展或待确认项不会升级完成。通用旧 QAEC 迁移也只允许转移此前已认证且满足新条件的记录。

E 完成需产生它的 A 完成，C 需声明证据完成；叶 Q 需回答 C 与前置 Q 完成，父 Q 需全部直接子 Q 与前置 Q 完成。两类 Q 都要自己的说明、准确依赖版本及足以作答的确认，不由文字存在或子 Q 完成自动确认。阴性结果也可回答；内容、范围、来源、关系或依赖变化使当前确认及下游待复核，旧正文与确认保留。

节点为带编号、状态、标题和保存内容摘录的卡片，证据可显示带表头的结果节选。Q卡片的独立箭头就地展开/收起子问题或已有AEC；点击卡片主体阅读完整详情，不进入另一张图。正文与历史在详情阅读，可平移、缩放、聚焦和查看全局。树与搜索会在同一画布定位；手动展开与镜头按项目记住，不改案例数据。原QAEC编辑器继续查阅原记录；右侧搭档的新发送已接入有限图变更，旧候选采用仍是每Q一组QAEC。接口及实际边界见[API参考](../../docs/research-workflow/research-graph-api.md)。

## 如何阅读结果

先看 results/summary.json 或论文摘要，再查 results/classified_samples.csv 中的同一样本配对。周期程序平均指标落在目标内，配对达标却只有45/120；批次差异限制“稳定复现”的结论。不要将程序均值或一个高成功批次替代逐样本联合事件和跨批次证据。

方法背景：[Di Lorenzo et al., Periodic cooking of eggs, 2025](https://www.nature.com/articles/s44172-024-00334-w)。原论文资料只用于背景和程序灵感；本例的模型、噪声、质构指数和数据完全独立且明确为合成。
